Docker y Docker Compose: Manual de Referencia

Aprende a empaquetar aplicaciones web, gestionar contenedores aislados y orquestar arquitecturas multicontenedor con la filosofía W3Schools.

1. ¿Qué es Docker y por qué se usa?

Docker es una herramienta de código abierto que permite empaquetar una aplicación con todas sus dependencias (librerías, sistema operativo base, configuraciones) dentro de un contenedor aislado. A diferencia de las máquinas virtuales tradicionales, los contenedores comparten el núcleo del sistema operativo anfitrión, lo que los hace extremadamente ligeros y rápidos.

Imagen (Image)

Plantilla de solo lectura que contiene las instrucciones para crear un contenedor (ej: nginx:alpine).

Contenedor (Container)

Instancia en ejecución de una imagen. Es un entorno aislado con su propia red y sistema de ficheros.

Dockerfile

Fichero de texto plano con los pasos automatizados para construir una imagen personalizada.

2. Comandos Esenciales de la CLI de Docker

Tabla de referencia rápida con los comandos que utilizarás constantemente en el módulo de Despliegue:

Comando Descripción Ejemplo Práctico
docker pull Descarga una imagen desde Docker Hub. docker pull mysql:8.0
docker run Crea y ejecuta un contenedor a partir de una imagen. docker run -d -p 8080:80 nginx
docker ps Lista los contenedores en ejecución (añade -a para todos). docker ps -a
docker stop / start Detiene o reanuda un contenedor en ejecución. docker stop mi_contenedor
docker logs Muestra la salida estándar o errores de un contenedor. docker logs -f mi_web

3. Orquestación con Docker Compose

Cuando tu aplicación requiere múltiples servicios interconectados (por ejemplo: un servidor web Nginx, un backend en Node.js y una base de datos MySQL), gestionar cada contenedor con comandos individuales es inviable. Docker Compose permite definir y ejecutar aplicaciones multicontenedor mediante un único fichero de configuración YAML (docker-compose.yml).

Ejemplo Real: Web + Base de Datos

version: '3.8'


services:

web-app:

image: node:18-alpine

ports:

- "3000:3000"

environment:

- DB_HOST=db-server

db-server:

image: mariadb:10.5

environment:

MYSQL_ROOT_PASSWORD: secreto123

MYSQL_DATABASE: dawfacil_db

4. Comandos Clave de Docker Compose

docker compose up -d: Construye y arranca todos los servicios definidos en segundo plano (*detached mode*).

docker compose ps: Muestra el estado actual de los contenedores del proyecto Compose activo.

docker compose logs -f: Muestra los registros combinados en tiempo real de todos los servicios.

docker compose down: Detiene y elimina los contenedores y las redes creadas.

⚡ Trucos para Exámenes del Módulo de Despliegue (2º DAW)
  • Persistencia de datos: Recuerda que si eliminas un contenedor de base de datos sin un volume configurado, perderás toda la información guardada.
  • Redes internas: Los servicios definidos en un mismo docker-compose.yml se pueden comunicar directamente usando el nombre del servicio como si fuera un dominio (ej: conectarse a db-server en lugar de localhost).
