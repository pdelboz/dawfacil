Creación de APIs RESTful con Express & Node.js

⏱️ 30 min de lectura • Nivel: Avanzado • Módulo: DWES (2º DAW)

Express es el framework de servidor más popular para Node.js. Facilita el enrutamiento HTTP, la integración de middlewares y la respuesta formateada en JSON para aplicaciones modernas.

1. Mapeo de Métodos HTTP (CRUD)

GET Obtener recursos
POST Crear recursos
PUT / PATCH Actualizar datos
DELETE Eliminar registro

2. Servidor Express Mínimo

const express = require('express');

const app = express();

app.use(express.json()); // Middleware para parsear JSON

app.get('/api/productos', (req, res) => {

res.json([{ id: 1, nombre: 'Teclado' }]);

});

app.listen(3000, () => console.log('Servidor en http://localhost:3000'));

⚡ Tip para el Examen de Backend

No olvides configurar los middlewares de CORS y la gestión centralizada de errores usando la firma (err, req, res, next) al final de tus rutas.
