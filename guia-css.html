CSS3, Flexbox y Grid: Manual de Referencia

Domina la estilización web avanzada al estilo W3Schools: selectores, modelo de caja, diseño unidimensional con Flexbox y maquetación bidimensional con CSS Grid.

1. Selectores y Especificidad en CSS

Los selectores determinan a qué elementos HTML se aplican las reglas de estilo. Su prioridad (especificidad) decide qué regla gana en caso de conflicto.

Tipo de Selector Sintaxis / Ejemplo Descripción
Selector de Etiqueta p { color: white; } Afecta a todas las etiquetas HTML de ese tipo.
Selector de Clase .btn-primary { background: blue; } Afecta a cualquier elemento con el atributo class="btn-primary".
Selector de ID #header-principal { width: 100%; } Afecta de forma única al elemento con el id="header-principal".
Selector Descendiente nav a { text-decoration: none; } Afecta a los enlaces <a> que se encuentran dentro de <nav>.

2. El Modelo de Caja (Box Model) y Box-Sizing

Cada elemento en HTML se representa como una caja rectangular compuesta por: Content (Contenido), Padding (Relleno interior), Border (Borde) y Margin (Margen exterior).

// Buena práctica universal para evitar errores de cálculo en anchos:

* {

box-sizing: border-box; /* Incluye padding y border dentro del ancho total */

}

3. Flexbox (Diseño Unidimensional)

Flexbox está diseñado para distribuir elementos en una sola dirección: una fila (horizontal) o una columna (vertical). Facilita enormemente el centrado y la distribución de espacios.

justify-content (Eje Principal)

Alinea los elementos a lo largo del eje principal. Valores comunes: flex-start, center, space-between, space-around.

align-items (Eje Cruzado)

Alinea los elementos en dirección perpendicular. Valores comunes: stretch, center, flex-start, flex-end.

Ejemplo de Contenedor Flexible (Navbar)

.navbar {

display: flex;

justify-content: space-between;

align-items: center;

padding: 1rem 2rem;

}

4. CSS Grid (Diseño Bidimensional)

CSS Grid permite crear estructuras basadas en cuadrículas con filas y columnas simultáneamente, ideal para maquetar layouts web completos o paneles de control.

Grid Adaptable Automático (Responsive)

.grid-tarjetas {

display: grid;

grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));

gap: 2rem;

}

⚡ Trucos para Exámenes de Lenguajes de Marcas o DWEC
  • Flexbox vs Grid: Usa Flexbox si los elementos van en una sola dirección (fila o columna). Usa Grid si necesitas controlar filas y columnas a la vez.
  • Unidades relativas: Prioriza el uso de rem o em en lugar de píxeles fijos (px) para garantizar que la web sea accesible y responsive.
