Git y GitHub: De cero a dominar ramas y conflictos

⏱️ 15 min de lectura • Nivel: Principiante • Módulo: ED (1º DAW/DAM)

Git es el sistema de control de versiones estándar en la industria del software. Te permite guardar el historial de cambios de tu proyecto, experimentar de forma segura mediante ramas y colaborar con otros programadores en repositorios remotos como GitHub.

1. Conceptos Fundamentales

En Git los archivos pasan por tres estados principales antes de guardarse definitivamente en el historial:

  • Working Directory: Carpeta de trabajo local con tus archivos modificados.
  • Staging Area (Index): Zona intermedia donde preparas los cambios con git add.
  • Repository (HEAD): Historial permanente donde confirmas tus cambios con git commit.

2. Comandos Básicos Imprescindibles

# 1. Inicializar repositorio local

git init

# 2. Comprobar estado del proyecto

git status

# 3. Añadir cambios al área de preparación

git add .

# 4. Confirmar versión con mensaje claro

git commit -m "feat: añadir estructura inicial de proyecto"

⚡ Tip para el Examen de Entornos

Diferencia siempre entre git pull (descarga y fusiona cambios del servidor) y git fetch (solo consulta cambios remotos sin alterar tus archivos locales).
