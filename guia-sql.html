SQL: Manual de Referencia Teórico y Práctico

Aprende la sintaxis oficial de SQL desde las consultas básicas hasta procedimientos almacenados, JOINs multitabla y reglas de integridad.

1. Introducción a SQL y RDBMS

SQL (Structured Query Language) es el lenguaje estándar ANSI/ISO para comunicarse con Sistemas Gestores de Bases de Datos Relacionales (RDBMS) como MySQL, PostgreSQL, Oracle y SQL Server.

DDL (Data Definition)

Define la estructura: CREATE, ALTER, DROP, TRUNCATE.

DML (Data Manipulation)

Manipula registros: SELECT, INSERT, UPDATE, DELETE.

DCL / TCL (Control)

Gestión de permisos y transacciones: GRANT, COMMIT, ROLLBACK.

2. Sentencias DML Fundamentales

2.1 Cláusula SELECT y Filtro WHERE

Permite extraer registros específicos especificando columnas, condiciones de filtrado y orden de salida.

Sintaxis Oficial

SELECT columna1, columna2

FROM nombre_tabla

WHERE condicion AND (otra_condicion OR valor IN (1, 2))

ORDER BY columna1 ASC, columna2 DESC;

2.2 Operadores de Filtrado

Operador Propósito Ejemplo
LIKE 'A%' Búsqueda por patrón (% coincide con cualquier texto) WHERE nombre LIKE 'Juan%'
BETWEEN a AND b Rango inclusivo de valores o fechas WHERE edad BETWEEN 18 AND 65
IS NULL / IS NOT NULL Comprueba valores nulos o ausentes WHERE telefono IS NOT NULL

3. Combinación de Tablas (JOINs)

Los JOINs permiten combinar registros de dos o más tablas en función de una columna común (clave foránea).

Tipos de JOINs en SQL

INNER JOIN

Devuelve únicamente las filas donde existe coincidencia en ambas tablas.

LEFT JOIN

Devuelve todas las filas de la tabla izquierda y las coincidentes de la derecha.

RIGHT JOIN

Devuelve todas las filas de la tabla derecha y las coincidentes de la izquierda.

FULL OUTER JOIN

Devuelve filas cuando hay coincidencia en cualquiera de las dos tablas.

Ejemplo de INNER JOIN multitabla

SELECT p.id, c.nombre AS cliente, pr.nombre AS producto

FROM pedidos p

INNER JOIN clientes c ON p.cliente_id = c.id

INNER JOIN productos pr ON p.producto_id = pr.id

WHERE p.estado = 'COMPLETADO';

4. Funciones de Agregación y GROUP BY / HAVING

Las funciones de agregación (COUNT, SUM, AVG, MIN, MAX) devuelven un único valor agrupando múltiples filas.

Agrupación con Filtro Posterior (HAVING)

SELECT departamento_id, COUNT(*) AS num_empleados, AVG(salario) AS salario_medio

FROM empleados

WHERE activo = TRUE

GROUP BY departamento_id

HAVING AVG(salario) > 2500;

⚡ Resumen de Claves para Examen de 1º DAW/DAM
  • WHERE filtra filas antes de agrupar.
  • HAVING filtra resultados agregados después del GROUP BY.
  • Todas las columnas seleccionadas en el SELECT que no estén en una función de agregación DEBEN aparecer en el GROUP BY.
