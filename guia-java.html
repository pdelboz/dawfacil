Java: Manual de Referencia Completo

Aprende toda la teoría de Java estructurada al estilo W3Schools: sintaxis, tipos de datos, estructuras de control, Programación Orientada a Objetos (POO), colecciones y manejo de excepciones.

1. Introducción y Sintaxis Básica

Java es un lenguaje orientado a objetos, fuertemente tipado y multiplataforma gracias a la Máquina Virtual de Java (JVM). Todo código ejecutable en Java debe estar dentro de una clase.

Estructura de un Programa en Java Main.java

public class Main {

public static void main(String[] args) {

System.out.println("¡Hola, DAWfacil!");

}

}

2. Tipos de Datos y Casting

En Java los tipos se dividen en Primitivos (almacenan valores directos) y De Referencia (almacenan referencias a objetos).

Tipo Tamaño Rango / Descripción Ejemplo
int 4 bytes Números enteros de -2,147,483,648 a 2,147,483,647 int edad = 20;
double 8 bytes Números decimales de alta precisión (hasta 15 dígitos) double nota = 8.75;
boolean 1 bit Valores lógicos: true o false boolean aprobado = true;
String Referencia Secuencia de caracteres (Objeto inmutable) String nombre = "Alex";

3. Estructuras de Control y Búcles

Sintaxis básica de las decisiones condicionales y los bucles más utilizados en Java.

// Bucle For Tradicional y For-Each

for (int i = 0; i < 5; i++) {

System.out.println(i);

}


String[] nombres = {"Ana", "Luis"};

for (String n : nombres) {

System.out.println(n);

}

// Bucle While y Switch

int opcion = 2;

switch (opcion) {

case 1 -> System.out.println("Inicio");

case 2 -> System.out.println("Ajustes");

default -> System.out.println("Salir");

}

4. Programación Orientada a Objetos (POO)

Java implementa los 4 pilares de la POO: Encapsulamiento, Herencia, Polimorfismo y Abstracción.

Ejemplo de Clase con Herencia y Polimorfismo

// Clase Base (Padre)

public abstract class Vehiculo {

protected String marca;

public Vehiculo(String marca) { this.marca = marca; }

public abstract void arrancar();

}


// Clase Hija

public class Coche extends Vehiculo {

public Coche(String marca) { super(marca); }

@Override

public void arrancar() {

System.out.println("El coche " + marca + " arranca con llave.");

}

}

5. Colecciones (ArrayList) y Excepciones (Try/Catch)

Uso de ArrayList y Manejo de Excepciones

import java.util.ArrayList;


try {

ArrayList<String> lista = new ArrayList<>();

lista.add("Java");

lista.add("Python");

System.out.println(lista.get(0));

} catch (IndexOutOfBoundsException e) {

System.err.println("Índice fuera de rango: " + e.getMessage());

} finally {

System.out.println("Operación finalizada.");

}

⚡ Consejos para el Examen de Programación (Java 1º DAM/DAW)
  • == vs .equals(): Usa siempre .equals() para comparar objetos o cadenas (String). El operador == solo compara posiciones de memoria.
  • Constructores: Si defines un constructor personalizado en una clase hija, debes llamar obligatoriamente a super() en la primera línea.
  • Atributos: Marca siempre los atributos de clase como private para cumplir la regla del encapsulamiento.
